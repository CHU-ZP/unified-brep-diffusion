Unified B-Rep Diffusion — GitHub Pages project homepage

The homepage is a standalone static website. It requires no package installation,
build step, external font service, or application server.

Content
  index.html             Page structure and English project copy
  assets/site.css        Responsive layout
  assets/site.js         Diagram enlargement
  assets/overview_entity_ddpm_reverse_9-16s.gif
                         Supplied reverse diffusion animation (7 seconds, looping)
  assets/overview_entity_ddpm_reverse_9-16s-poster.jpg
                         Final animation frame used as the static poster
  assets/figures/        Four editable method diagrams

Local preview
  From the repository root:
    python3 -m http.server 8000 --directory docs
  Open http://localhost:8000/
  Opening docs/index.html directly in a browser also works.

The reverse diffusion GIF loops continuously. It has no replay,
playback or fullscreen controls. Reduced-motion preferences show a static
poster. Method diagrams can be enlarged separately.

GitHub Pages — simplest setup
  1. Create a GitHub repository and upload the docs/ directory.
  2. Open repository Settings → Pages.
  3. Choose "Deploy from a branch", your default branch, and the /docs folder.
  4. Save. GitHub provides the final *.github.io project URL.

  If Pages publishes the repository root instead of /docs, upload the root
  index.html as well. It redirects to docs/ and preserves query parameters
  and section anchors. Without it, GitHub renders README.md as the homepage.

All asset links are relative, so the same files support both a project path
such as /repository-name/ and a username.github.io root site.

The displayed headline metrics come from the supplied project description:
  1B parameters; +6 percentage points in Valid B-Rep Rate and −8.5% in MMD-CD
  relative to the hierarchical cascade baseline.
