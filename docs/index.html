The method

Geometry and topology, jointly modeled.

We represent vertices, edges and faces as entity tokens in a shared Diffusion Transformer. Geometry and connectivity evolve together, with soft topology guiding attention throughout denoising.

01 / Representation

Hybrid geometry.
One token per entity.

Analytic curves and surfaces retain native parameters. Curve and surface VAEs encode free geometry into compact latents.

Role-specific adapters map vertices, edges and faces to a common token space. Topology remains a separate relation channel.

02 / Joint diffusion

Soft topology guides
geometric refinement.

The Transformer predicts geometry and connectivity in parallel. Soft edge–vertex and coedge–face relations feed back as attention bias.

A topology-aware noise schedule moves from coarse structure to stable relations and fine geometry. Unified masks specify the known conditions.

One conditioning interface Unconditional generation Topology restoration Completion Local infilling

03 / Reconstruction

Consistent topology.
Shared boundaries.

Geometry is decoded from native parameters or VAE latents. A MILP projects predicted relations under loop, orientation, manifold and connectivity constraints.

Shared endpoints and one polyline per edge give neighboring faces the same boundary indices, connecting the reconstructed mesh.
